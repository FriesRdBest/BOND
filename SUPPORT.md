# Support

Thank you for using BOND.

BOND is an independent portfolio project. It is provided as a working demonstration of an engineering assurance workflow, not as a supported production service.

## Before opening an issue

Review the following records:

- [README](README.md) for the product overview and reviewer walkthrough.
- [Architecture](docs/ARCHITECTURE.md) for system boundaries.
- [Local development](docs/LOCAL_DEVELOPMENT.md) for setup and commands.
- [Known limits](docs/KNOWN_LIMITS.md) for incomplete capabilities and maintenance findings.
- [Security](docs/SECURITY.md) for credential and vulnerability reporting guidance.

## Asking for help

Open a GitHub issue when you have a reproducible problem, a documentation correction, or a focused question about the repository.

Include:

- What you expected to happen.
- What actually happened.
- The command, page, or workflow involved.
- Relevant error output, with secrets and credentials removed.
- Your operating environment when relevant.

## Hosted demonstration

The hosted demonstration uses free Streamlit Community Cloud and Supabase allowances. It may sleep, pause, restart, or impose resource limits. Continuous availability is not promised.

The public demonstration uses synthetic evidence and simulated actions. It does not modify production infrastructure.

## Security issues

Do not open a public issue for a suspected security vulnerability. Follow the private reporting process in [SECURITY.md](SECURITY.md).
